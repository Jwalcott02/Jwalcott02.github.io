Principles

How I build

01

Measure before claiming

In TakeMeter I tested a fine-tuned model against a zero-shot LLM on the same held-out data, then reported what the numbers actually showed, including when training lost.

02

Ground answers in sources

My retrieval projects pull relevant passages first and cite them, so a user can check where an answer came from instead of trusting it blindly.

03

Build in safeguards

Public AI endpoints need limits. I add rate limiting, and I like keeping a human in the loop for decisions that matter.
